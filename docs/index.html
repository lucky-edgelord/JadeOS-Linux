Appliance Linux for Jade Vault

Jade, full screen, on real hardware.

A small Linux that boots straight into Jade Vault, with a real file system, a real shell, real Node.js, MicroPython and SQLite behind it. The Android app's experience, on a thin client or mini PC.

Download the image Source on GitHub

About 150 MB compressed · raw disk image for USB or internal drive · 64-bit UEFI x86 · not yet tested on a physical machine (see status)

What you get

No browser sandbox in the way: the app talks to the actual machine.

Files

Real file system

The vault is a folder, /home/jade. Other programs can read and write the same files and the app updates live.

Shell

Real BusyBox shell

Pipes, redirects, globbing, cd anywhere. The Shell tab and the agent's shell tool run the same sh. No WebAssembly.

Runtimes

Node, MicroPython, SQLite

Real node, micropython and sqlite3 on the PATH, plus curl, nano, iw and wpa_supplicant.

Jade

Jade's own commands

jade, flow, crontab, search, tags and the rest work from the shell too.

Screen

WebKit on the GPU

WPE WebKit through Cog straight on KMS/DRM with Mesa, so WebGL and the Live2D avatar run accelerated.

Appliance

Safe to power off

Read-only root. Your data lives on its own partition that grows to fill the disk on first boot.

Install

Four steps. You need a USB stick (4 GB or more) or a spare drive.

  1. Download

    Get jadeos-wyse3040.img.gz (and the .sha256 file) from the latest release. The filename says Wyse 3040, but it is the one image for every supported machine.

  2. Write it to a stick

    On Linux or macOS (check the device name first, dd overwrites it):

    gunzip -c jadeos-wyse3040.img.gz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync

    On Windows use balenaEtcher or Rufus in DD mode.

  3. Boot it

    Press F12 at power-on and choose the stick. Turn Secure Boot off, the image is not signed. On a Dell Wyse 3040 the BIOS password, if one is set, is often Fireport.

  4. Wait a minute

    The first boot grows the data partition to fill the stick or drive, then Jade appears full screen. To make it permanent, dd the image onto the internal drive from any live Linux.

Network

Ethernet

Nothing to do

Every wired port (eth0, enp0s25, eno1…) asks for an address with DHCP at boot.

Wi-Fi

Use a USB adapter

Realtek, MediaTek, Atheros and Ralink USB drivers and firmware are included, plus Intel cards. Broadcom is not. Then, in the Shell tab:

jade-wifi "My network" "password"

Hardware

Any x86-64 machine with 64-bit UEFI and at least 2 GB of RAM should boot it. The Intel graphics drivers cover most thin clients and mini PCs; other GPUs fall back to software rendering.

How it works

The Jade Vault page is unchanged except for two swaps: its file system class and its shell runner now talk to a small local daemon instead of the browser sandbox.

jaded listens only on localhost, refuses foreign Host headers, and every call needs a per-boot token that only the page it serves carries, so another web page cannot drive the shell.

The system is Buildroot 2025.02 with Linux 6.12, GRUB for 32- and 64-bit EFI, eudev, BusyBox init, WPE WebKit 2.48 with Cog, Mesa, Node.js, MicroPython and SQLite, on a GPT disk with an EFI partition, a read-only root and a data partition.

Build it yourself

CI builds the image (4–5 hours on a GitHub runner), boots it in QEMU and publishes it. Locally:

git clone --depth 1 -b 2025.02.6 https://github.com/buildroot/buildroot ../buildroot
tools/fetch_page.sh
make -C ../buildroot BR2_EXTERNAL=$PWD O=$PWD/output wyse3040_defconfig
make -C ../buildroot BR2_EXTERNAL=$PWD O=$PWD/output
